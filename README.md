# CRUD ML Web Application

A Flask-based CRUD web application that allows users to Create, Read, Update, and Delete records through a simple HTML/CSS interface. Data is stored in a JSON file (db.json) without using a traditional database, making the application lightweight and easy to use.

#Features
Create, Read, Update, Delete records
JSON file-based data storage
Responsive UI with HTML & CSS
Automatic data persistence
ML integration ready
# Technologies Used
Python
Flask
HTML
CSS
JSON
# Run the Project
pip install flask
python app.py
